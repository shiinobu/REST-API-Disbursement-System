# Security Policy

## Reporting a Vulnerability

Please do not disclose security vulnerabilities in public issues.

If you discover a security issue, contact the repository owner privately through GitHub so it can be reviewed before public disclosure.

## Scope

Security issues include, but are not limited to:

- Authentication or authorization bypass
- Credential or secret exposure
- SQL injection
- Sensitive data exposure
- JWT validation weaknesses
- Unexpected access to protected disbursement operations

Please include enough information to reproduce the issue safely, without publishing real credentials or sensitive data.
